# Arcadia Redux custom game template
For lua projects. Contains all essential libraties and utilities for quick start.
Contains:
 - WebApi for [backend server template](https://github.com/arcadia-redux/ar_webserver_template).
 - Event Driver
 - Timers
 - Key Values
 - Extended Disable Help
 - Toasts
 - Chat commands
 - Common events, filters and base lua extensions (table, string)
 - Precache entry

## Using this template [WIP]
Create a new repo using button above, clone repo and replace all occurances of `ar_custom_game_template` in files with snake_case custom game name.

Run `npm install` to link repo with dota, run the custom game from console.
